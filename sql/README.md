# SQL Analysis

This folder contains the SQL scripts used for the Diabetes Hospital Readmission Analysis project.

## Files

### 01_data_exploration.sql
Explores the dataset by examining patient demographics, admission characteristics, discharge information, and clinical variables.

### 02_data_cleaning.sql
Identifies and cleans data quality issues, including invalid and missing categorical values while preserving the original dataset.

### 03_readmission_analysis.sql
Analyses hospital readmission patterns by investigating demographics, healthcare utilisation, hospital stay, and diagnosis characteristics associated with patient readmission.
